# cypress-tests-automaticity
## 1. Prerequisites
Install these on your machine before cloning the repository:
1. **Git** - any recent version
2. **Node.js** - version 24.20 or newer
3. **Google Chrome** - latest
## 2. Clone and run
Run the following commands
```bash
git clone https://github.com/andrianasavanovic/cypress-tests-automaticity.git
cd cypress-tests-automaticity
npm install
npx cypress open
```
1. Select **E2E testing**
2. Select **Chrome** and click **Start E2E Testing in Chrome"
3. Click **`registration.cy.js`**
